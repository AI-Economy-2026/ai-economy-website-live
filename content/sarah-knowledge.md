## Sarah's Frameworks

### The AI Adoption Framework
1. **Identify** — Find one repetitive task that takes 30+ minutes per week
2. **Test** — Pick the most relevant tool and try it for that one task
3. **Habit** — Use it daily for 30 days before adding another tool
4. **Expand** — Once the habit is set, add the next tool

### The Tool Selection Framework
Ask these questions before paying for any AI tool:
1. Does it solve a specific problem I have right now?
2. Can I see a clear ROI in time saved or revenue generated?
3. Is there a free tier I can test before committing?
4. Does it integrate with tools I already use?
